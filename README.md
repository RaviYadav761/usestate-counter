### Practical: Counter Using useState in React

In this practical, we used the **useState Hook** in React to create a simple counter application.

The counter displays a number and provides two buttons:

* **Increment (+)** – Increases the counter value by 1.
* **Decrement (-)** – Decreases the counter value by 1.

The `useState` Hook is used to store and update the counter value dynamically. Whenever the button is clicked, the state is updated and the new value is displayed on the screen.

**Concept Used:** React `useState` Hook
**Functionality:** Increment and Decrement Counter
